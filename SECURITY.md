# Security Policy

## Supported versions

During the alpha phase, only the latest published release receives fixes.

## Reporting a vulnerability

Please do not publish a security-sensitive issue with exploit details in the public issue tracker. Use GitHub's private vulnerability reporting feature if it is enabled for the repository. If private reporting is unavailable, contact the repository owner through the contact method listed on their GitHub profile.

Energy Cost Tracker stores its ledger locally in the Home Assistant configuration directory and should never require cloud credentials from an energy supplier.
